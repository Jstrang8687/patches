Use a GitHub access key instead

A GitHub access key for the patches repository also works. You only have to do this once per device.

  1. Sign in to GitHub, then open Create a new access key.
  2. Name it Patches admin and pick an expiration (1 year is fine).
  3. Under Repository access, choose Only select repositories and pick patches.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Click Generate token, copy it, and paste it below.
